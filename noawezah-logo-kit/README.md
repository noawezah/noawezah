# noawezah. logo kit

Original Neue Machina Ultrabold wordmark with the original -0.055em tracking, font kerning, and lime dot. Rebuilt from the supplied font outlines; no bitmap tracing. SVG, PDF and EPS contain real vector paths. Production logo files do not need fonts installed.

## Start here

- Dark background: svg/noawezah-for-dark-backgrounds.svg (transparent).
- White or light background: svg/noawezah-for-light-backgrounds.svg (transparent).
- Fixed dark ground: svg/noawezah-on-ink.svg or pdf/noawezah-on-ink.pdf.
- Fixed white ground: svg/noawezah-on-white.svg or pdf/noawezah-on-white.pdf.
- Full guide: pdf/noawezah-brand-guide.pdf.

## Folders

svg/ - six outlined, scalable logo masters.
pdf/ - vector logo on Ink, vector logo on White, and the five-page brand guide.
png/ - all six variants, 1000 / 2000 / 4000 px wide, with alpha where appropriate.
webp/ - all six variants, 1000 / 2000 px wide, lossless and alpha where appropriate.
eps/ - all six variants in legacy PostScript vector format (RGB).
jpg/ - Ink and White backgrounds, 2000 px wide.
favicons/ - existing site icon, unchanged SVG, multi-size ICO, Apple 180 px, 192 / 512 px PNG, web manifest.
fonts/ - supplied Neue Machina Light / Regular / Ultrabold and Satoshi variable, copied unchanged; Satoshi license and font notes.
colors/ - palette values, theme tokens and a GIMP-compatible swatch palette.
source/ - original screenshot, geometry data and editable text reference.

## Variants

for-dark-backgrounds: Chalk letters + Signal dot, no background.
for-light-backgrounds: Ink letters + Signal dot, no background.
on-ink: Chalk letters + Signal dot on Ink.
on-white: Ink letters + Signal dot on White.
mono-ink: all Ink, no background; suitable for Signal or light backgrounds.
mono-white: all White, no background.

## Color and themes

Ink #10110F; Chalk #F4F3E9; Signal #DFFF65.
Supporting colors: Muted #A7AA9B; Line #35372E; White #FFFFFF.
Dark, white, chalk and signal theme mappings are in colors/palette.json.
The white/chalk supporting theme tokens are adapted from the site's light sections.
CMYK figures in the guide are approximate mathematical conversions, without an ICC profile. Confirm production print colors with your printer.

## Use and edit

Keep the aspect ratio. Master artboards include recommended clear space of half the visible logo height. Recommended minimum wordmark width: 120 px on screen or 30 mm in print; proof any smaller use.
For a tiny browser or app icon, use favicons/ rather than the complete wordmark. The favicon is the existing site's symbol, not a new monogram.
EPS variants without a ground omit the background shape; EPS does not have an alpha channel. Use a compatible vector editor to place or export them.
Editable text reference: install Neue Machina Ultrabold and open source/noawezah-editable-text.svg. Editors can interpret font metrics differently; use the outlined masters for production.
The screenshot's colored edge fringes are screen antialiasing artifacts; the vector masters preserve the actual logo colors and contours.

Fonts are the files supplied in the site folder. No Neue Machina license document was present. Use and sharing follow your original license; the included font notes identify the foundry. Satoshi's supplied license is included.
